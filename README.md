## Overview

A premium, dark-themed personal portfolio designed to target modern product and tech teams — built with performance, accessibility, and visual polish in mind. Combines editorial typography with smooth motion design to create a memorable first impression.

## Getting Started

### Prerequisites

- Node.js `v18.17` or higher
- npm `v9+`

### Installation

```bash
# Clone the repository
git clone https://github.com/Akankshapilli/akanksha-portfolio.git

# Navigate into the project
cd akanksha-portfolio

# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Deployment

This project is deployed on **Vercel** with automatic deployments on every push to `main`.

```bash
# Push to deploy
git add .
git commit -m "your message"
git push origin main
```

Vercel picks it up automatically — no manual steps needed.
